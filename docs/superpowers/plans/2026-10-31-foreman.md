# Foreman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A lease desk for coding agents. An agent must hold a file's lease before editing it. When the holder commits, the next agent in the queue gets the file plus the commit SHA and summary. It merges that commit and reviews it before editing. Other agents can ask the commit's author agent questions without seeing its transcript. You run this on your own laptop from Monday.

**Architecture:**
- **Leases.** One Terse `RepoActor` per repo holds leases, queues, notices and commit authorship.
  - The lease logic lives in a pure module (`leases.ts`), so it can be tested without the runtime. The actor is a thin wrapper that assigns the new state on each call.
- **Server.** One Bun server (`server.ts`) is the only thing agents talk to. It forwards HTTP calls to the actor, and posts the resulting events to Relay `#foreman` and to a Supabase table.
- **Agent hooks.** Claude Code hooks and git hooks call a small CLI (`foreman`), which calls the server. Codex uses the same CLI from its shell and gets notices by Relay DM.

**Tech Stack:**
- Bun ≥1.4.2, TypeScript 5.9
- `durable-actors@0.14.6`
- `@agent-relay/sdk@15.0.1` + `zod`. Relay needs Node 22 or 24.
- `@supabase/supabase-js`
- `freestyle-sandboxes`
- Claude Code hooks

**Spec:** `foreman-brief.md` (all three sections: core loop, combined plan with review, hosting).

## Global Constraints

- All code is written on-site, Sat Oct 31, 11:00–16:00. Crash recovery is **not** a feature and is not demoed.
- **Primary set-up: two people, two laptops, each with its own clone of the same GitHub repo.** Both are connected to one shared Foreman server. Worktrees on one machine work the same way. In the plan, "checkout" means a clone or a worktree.
- **Agents.** One agent per checkout.
  - Agent ID is `claude:<session_id>` for Claude Code and `relay:<handle>` for Relay/Codex.
  - Label is `<tool>@<git config user.name, first word, lowercased>`, e.g. `claude@rishi`. Both clones usually share a folder name, so the folder can't be the label.
- **Repo ID.** `git remote get-url origin`, normalized to `host/owner/repo`:
  - strip the protocol, `git@` and `.git`;
  - turn `:` into `/`;
  - lowercase it;
  - take the first 16 hex chars of its sha1.

  An SSH clone and an HTTPS clone of the same repo must get the same ID. A repo with no origin falls back to sha1 of the realpath of `git rev-parse --git-common-dir`, which only works on one machine.
- **Commits must reach the other laptop.** `git merge <sha>` fails if the commit only exists on the holder's machine.
  - **On commit, push first.** The post-commit hook pushes `HEAD` to the hidden ref `refs/foreman/<sha>` on origin with `git push origin HEAD:refs/foreman/<sha>`. This touches no branch, and branch protection doesn't apply to it. Then it releases.
  - **Waiter's instructions.** The notice tells the waiter to run `git fetch origin refs/foreman/<sha> && git merge <sha>`.
  - **If the push fails, keep the lease.** The hook warns on stderr. The waiter must never be handed a commit it can't fetch; the lease expires after TTL instead.
- **Server reachability.**
  - **During the build:** the server runs on one laptop, bound to `0.0.0.0`, and your friend sets `FOREMAN_URL=http://<lan-ip>:7300`.
  - **Final:** Freestyle (Task 11).
  - **Relay** uses a hosted workspace (`relay init --hosted`), because a local Relay server is only reachable on one machine.
- **Paths.** Files are keyed by repo-relative POSIX path. Files outside the checkout are never leased.
- **Constants:**
  - `TTL_MS = 20*60_000` (idle lease expiry)
  - `LIVE_MS = 10*60_000` (author counts as "live" if seen this recently)
  - `STOP_POLL_MS = 3000`
  - `STOP_MAX_MS = 540_000`; the Stop hook's `"timeout"` is 600
  - `PORT_BASE = 3001`
  - `CLI_TIMEOUT_MS = 2000`
- **Server.**
  - URL comes from env `FOREMAN_URL`, default `http://127.0.0.1:7300`.
  - It is the only exposed port. Terse dev stays on `127.0.0.1:7111`.
- **Hooks fail open.** If the server is unreachable or slow, the CLI prints a one-line warning to stderr, exits 0 and prints no JSON. A dead Foreman must never block an agent.
- **No long-running actor calls.** An actor call holds the actor across `await`. The Stop hook therefore polls `/api/notices` from the client. Nothing in the actor waits.
- **`@Persisted` fields are saved only on assignment.** Always assign the new state object (`this.state = r.state`) and never mutate it in place.
- Claude Code hook outputs (check against current hooks docs in Task 4, step 1):
  - PreToolUse deny: `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":R}}`
  - PostToolUse context: `{"hookSpecificOutput":{"hookEventName":"PostToolUse","additionalContext":T}}`
  - Stop: `{"decision":"block","reason":R}`

## Review Focus

1. **An agent re-claims its own file on every Edit.** This must be idempotent and refresh `touched`, not queue the agent behind itself. Test: Task 1, `claim is idempotent for holder`.
2. **Paths arrive absolute, relative, with `./`, or outside the repo** (`~/.claude/plans/x.md`, `/tmp/x`). Inside paths normalize to the same key. Outside paths are allowed with no lease. Test: Task 4, `toRepoPath`.
3. **A commit includes files the agent never leased** (human edits, generated files), or the commit is by a human. Release must be a no-op for those files, with no crash and no notices. Test: Task 1, `release ignores files not held`.
4. **The server is down or slow while an agent edits.** The hook fails open within 2s. Test: Task 4, `cli fails open`.
5. **The two laptops cloned with different URLs** (`git@github.com:o/r.git` vs `https://github.com/o/r`). They must land in the same RepoActor, or leasing silently does nothing. Test: Task 4, `repoKey normalizes ssh and https`.
6. **The holder's commit push fails** (offline, no push rights). The lease must stay with the holder rather than hand over a commit the other laptop can't fetch. Test: Task 4, `post-commit keeps lease when push fails`.
7. **The Stop hook loops forever.** If `stop_hook_active` is true and the agent is not waiting, allow the stop. A waiter that ends its session is removed from every queue. Tests: Task 5, `stop allows when not waiting`; Task 1, `releaseAll removes agent from queues`.

`server/src/types.ts` (shared by every task; the CLI imports it by relative path):

```ts
export type AgentId = string
export interface AgentRef { id: AgentId; label: string; sessionId?: string }
export interface Lease { file: string; holder: AgentRef; task?: string; since: number; touched: number }
export interface Waiter { agent: AgentRef; since: number }
export interface CommitInfo { sha: string; summary: string; stat: string }
export type Notice =
  | { kind: "granted"; file: string; from?: AgentRef; commit?: CommitInfo; uncommitted?: boolean }
  | { kind: "expired"; file: string }
  | { kind: "revoked"; file: string }
  | { kind: "question"; qid: string; sha: string; from: AgentRef; text: string }
export interface RepoState {
  leases: Record<string, Lease>
  queues: Record<string, Waiter[]>
  outbox: Record<AgentId, Notice[]>
  commits: Record<string, { author: AgentRef; files: string[]; summary: string }>
  lastSeen: Record<AgentId, number>
  ports: Record<AgentId, number>
  nextMigration: number
}
export type EventType = "claimed" | "blocked" | "released" | "granted" | "expired" | "revoked"
  | "left" | "review" | "question" | "answer"
export interface FEvent { type: EventType; agent: AgentRef; file?: string; sha?: string; text?: string; to?: AgentRef }
export interface Result<T> { state: RepoState; events: FEvent[]; value: T }
export interface Blocked { file: string; holder: AgentRef; task?: string; position: number }
```

### Task 1: Lease core (pure logic) — 11:00–11:45

**Files:** Create `foreman/package.json`, `server/package.json`, `server/src/types.ts`, `server/src/leases.ts`, `server/src/leases.test.ts`. `git init` in `foreman/`.

**Interfaces — Produces (all pure, `now` passed in):**
- `emptyState(): RepoState`, with `nextMigration` set to 1
- `claim(s, agent: AgentRef, files: string[], now: number, task?: string): Result<{ granted: string[]; blocked: Blocked[] }>`
- `release(s, agent, files: string[], now, commit?: CommitInfo): Result<{ released: string[] }>`
  - Only releases files `agent` holds.
  - Hands each released file to the head of its queue, giving that waiter a `granted` notice with `from` and `commit`.
  - When `commit` is given, records `commits[sha]` with all the files in the commit that the agent held.
- `releaseAll(s, agent, now): Result<{ released: string[] }>`
  - Like `release`, but waiters get `granted` with `uncommitted: true`.
  - Also removes `agent` from every queue and from `ports`, and emits `left`.
- `expire(s, now, ttlMs): Result<{ expired: string[] }>`
  - Releases leases with `touched + ttlMs <= now`.
  - The holder gets an `expired` notice and waiters are granted.
- `revoke(s, file, now): Result<{ revoked: boolean }>`. The holder gets a `revoked` notice; the next waiter is granted.
- `takeNotices(s, agentId): Result<Notice[]>`. Returns the outbox and clears it.
- `isWaiting(s, agentId): boolean`
- `nextAlarm(s, ttlMs): number | null`. Returns min(`touched`) + ttl, or null when there are no leases.
- `leasePort(s, agent, base = 3001): Result<number>`. Stable per agent; the lowest free port at or above `base`.
- `takeMigration(s, agent): Result<number>`. Returns `nextMigration`, then increments it.
- `ask(s, sha, from, text, now, qid): Result<{ author?: AgentRef; live: boolean }>`
  - `live` = `now - lastSeen[author.id] < LIVE_MS`.
  - When live, push a `question` notice to the author.
- Every call that takes an `agent` sets `lastSeen[agent.id] = now`.
- Events:
  - `claim` emits `claimed` per granted file and `blocked` per blocked file.
  - `release`, `releaseAll`, `expire` and `revoke` each emit their own type per file.
  - Every hand-off to a waiter also emits `{type:"granted", agent: previousHolder, to: waiter, file, sha?}`.
- **Copy-on-write:** never mutate the input `s`. Return new objects and use `structuredClone` at entry.

  - `claim is idempotent for holder` → A claims twice at t=1, t=5. Still granted, `touched == 5`, `queues["auth.ts"]` is undefined or empty.
